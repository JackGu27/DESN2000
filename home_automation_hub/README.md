Read Me for Marker

Upon running the clock will start at 4am and time will pass faster than normal.

Light sensor:
When set to automatic mode, if the light sensor has light the blinds will be up indicated by the RED light on the display as well as the two LED's for backup. Upon decreasing light level, the blinds will reach mid (green) and then blue (down). Touch the touchscreen for manual control

Smart Plug:
at 6-7 and 3:30 - 4:30. This is the heating times for the espresso machine. There is also manual override with the touchscreen.

UI:
There is a light level status bar, blind 1,2 and smart plug status lights. There is also auto buttons by default, and then automatic control buttons.

Doorbell:
Open pressing the right button (P.011) the doorbell chime will play.
